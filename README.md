# Estúdio de Ideias

Sistema web de gestão do conhecimento acadêmico desenvolvido para o curso de Tecnologia em Análise e Desenvolvimento de Sistemas da PUC Minas Virtual.

O **Estúdio de Ideias** funciona como um repositório digital de projetos acadêmicos, permitindo o armazenamento, organização e consulta de trabalhos desenvolvidos por estudantes ao longo da graduação. Inspirado em plataformas como o Google Scholar, o sistema busca preservar o conhecimento produzido na universidade e facilitar seu acesso por estudantes, pesquisadores e educadores.

## Funcionalidades

* Pesquisa de projetos por palavras-chave;
* Filtros e categorização por áreas de conhecimento;
* Sistema de favoritos;
* Visualização de estatísticas da plataforma;
* Submissão de projetos para moderação;
* Consulta e compartilhamento de trabalhos publicados.

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap
